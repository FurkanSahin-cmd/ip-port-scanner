# 🔍 IP & Port Scanner

A web-based network reconnaissance tool built with Python and Flask. The application allows users to scan IP addresses and ports through a simple web interface and identify accessible network services.

## 🚀 Features

- 🌐 IP address scanning
- 🔌 TCP port scanning
- 🧩 Service detection
- ⚡ Web-based scanning interface
- 📊 Scan results displayed directly in the browser
- 🔄 Frontend-to-backend communication through Flask API
- 🛡️ CORS support for API requests

## 🛠️ Tech Stack

### Frontend
- HTML5
- CSS3
- Vanilla JavaScript

### Backend
- Python 3
- Flask
- Flask-CORS
- Requests

### Networking
- Socket Programming
- TCP/IP
